# AGENTS.md

## Project

Static React + Vite demo for CloudCore AI Network Monitoring PoC.

## Commands

- Install: `npm install`
- Run dev server: `npm run dev`
- Build: `npm run build`

## Rules

- Use static mock data and local state only.
- Do not add backend, database, authentication, real AI API, or real email sending.
- Keep UI professional, dashboard-like, and suitable for a 3-5 minute university demo video.
- Preserve the human-in-the-loop principle: AI recommends, humans decide.
- When changing report pages, keep all five report variants and route mappings consistent.
