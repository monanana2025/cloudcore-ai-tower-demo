# CloudCore AI Network Monitoring PoC

Static clickable React demo for a university prototype showing AI-assisted network traffic anomaly detection, human review, report generation, and report sharing.

## Setup

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal, usually `http://localhost:5173`.

## Demo Notes

- Static mock data only.
- Local browser state only.
- No backend, database, real authentication, real AI API, or real email sending.
- The login button always enters the demo dashboard.
- Report actions update the in-page action log without reloading.
